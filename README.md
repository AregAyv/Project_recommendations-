# Steam Game Recommender

A game recommendation system trained on the [Steam Games Dataset](https://www.kaggle.com/datasets/antonkozyriev/game-recommendations-on-steam).

For backend, FastAPI was used, and for frontend, Streamlit. Supports recommending games based on a specific title given by a game's app_id, which you can get from [SteamDB](https://steamdb.info), or from a user's Steam profile.

## Features

- **7 recommendation models**, trained and compared on the same data:
  - `collaborative_knn` — similarity based on shared player behavior
  - `collaborative_cosine` — same idea, full pairwise cosine similarity
  - `content_based` — similarity based on game metadata (tags, price, decade)
  - `als` — Alternating Least Squares matrix factorization (`implicit`)
  - `popularity` — baseline: globally most-liked games
  - `lightfm` — hybrid collaborative + content model, optional
  - `hybrid` — weighted rank fusion combining any subset of the models above

## Architecture

```
Streamlit frontend  -->  FastAPI backend  -->  frozen model artifacts (.joblib)
  (streamlit_app.py)       (app.py)              (trained once, loaded at startup)
```

- **`main.py`** — trains models with the best params found from grid search, and evaluates them.
- **`freeze_models.py`** — trains the models one last time and saves the artifacts.
- **`app.py`** — the FastAPI service. Loads the frozen artifacts once at startup and serves recommendations; never trains anything.
- **`steam_client.py`** — wraps the Steam Web API for pulling a user's owned games from their profile.
- **`streamlit_app.py`** — the frontend, in its own `frontend/` folder. Calls the API over HTTP; holds no data itself.

## Setup

### Prerequisites

Check `requirements.txt` and `requirements-streamlit.txt` for dependencies. A public Steam profile (Game details set to Public) is required for the Steam-profile recommendation option.

### Install dependencies

```bash
python3 -m venv venv311
source venv311/bin/activate
pip install -r requirements.txt
```

### Train and evaluate models

```bash
python3 main.py
```

Prints a comparison table across all models and metrics, and saves results to `results/`.

### Freeze models for deployment

```bash
python3 freeze_models.py
```

Produces `model_artifacts/model_artifacts.joblib`. Run this once (or whenever you retrain on new data); the API never trains anything itself.

### Run the API locally

```bash
export STEAM_API_KEY=your_key_here
uvicorn app:app --reload --port 8080
```

Open **http://localhost:8080/docs** for the interactive API.

### Run the frontend locally

```bash
cd frontend
pip install -r requirements-streamlit.txt
streamlit run streamlit_app.py
```

By default it points at `http://localhost:8080`; set `API_BASE_URL` to point elsewhere (e.g. a deployed API).

## API endpoints

| Endpoint | Description |
|---|---|
| `GET /health` | Status check; lists available models |
| `GET /models` | Lists available models |
| `GET /recommend` | Recommend games similar to a given `app_id`, using a chosen `model` |
| `GET /recommend_from_profile` | Recommend games based on a Steam profile's most-played title |

All endpoints accept a `k` parameter for how many recommendations to return.

## Finding a game's app_id

- **Steam store URL** — the number is right in the URL, e.g. `store.steampowered.com/app/413150/Stardew_Valley/` → app_id is `413150`.
- **[SteamDB](https://steamdb.info)** — search by name, app_id listed clearly for every game.

## Evaluation metrics

Every model is evaluated on the same held-out, chronologically split test set:

- **precision@k / recall@k** — standard hit-rate metrics
- **MRR** — how high the first correct recommendation ranks
- **MAP@k** — rewards getting hits early in the list
- **Coverage** — % of the catalog ever recommended (catches models that only suggest blockbusters)
- **Diversity** — how varied a single recommendation list is
- **Novelty** — how niche vs. mainstream the recommendations are

## Known limitations

- `lightfm` can be difficult to install on newer Python versions (3.14+); this project was built and tested on Python 3.11.
- `/recommend_from_profile` requires the target Steam profile's "Game details" privacy setting to be Public.
